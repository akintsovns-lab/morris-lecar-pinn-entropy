# LIMITATIONS.md

1. Одна параметризация модели Морриса–Лекара (SNIC, класс I); класс II (Хопф) не исследован.
2. Окно реконструкции PINN 1000 мс (D-05): вблизи I_crit (критическое замедление, T ∝ (I − I_c)^(−1/2)) окно содержит 0–2 спайка; энтропии на нём не равны энтропиям длинного окна.
3. Только CPU; небольшие сети (2 слоя × 20 нейронов на сегмент), смешанная точность (D-01).
4. Сокращённая матрица сценариев (D-13) и сетка токов PINN (D-06).
5. Основная PINN транcдуктивна (I известен, сеть на каждый ток); обобщение по току проверено отдельным параметрическим экспериментом.
6. Архитектура PINN разработана в пилотах с доступом к эталону на четырёх токах (D-14); логи пилотов не сохранены.
7. Конвенция «покой» (SD < 0.1 мВ → все энтропии = 0, D-08) вводит порог: при шуме реконструкции окон покоя перестают быть «покоем», направление скачка энтропии на переходе меняется (AUC → 0), хотя ε по |наклону| может оставаться малым. Чувствительность к порогу проверена только разведочно (D-23).
8. Базовая линия ODE-LSQ запущена на 5 масках двух условий (D-19); при известных параметрах она точнее PINN — преимущество PINN при неизвестных параметрах не проверялось.
9. При n = 10 реализаций и большом числе точных совпадений ε (детектор выдаёт один из немногих интервалов сетки) мощность критериев Уилкоксона ограничена; совпадения трактуются как «нет различий» по предрегистрированному правилу.
10. Параметрическая PINN (t, I) → (V, w) при бюджете основного протокола не обобщает по току через порог (relL2 V на тестовых токах ≈ 0.14, w не восстановлена); выводы бенчмарка опираются только на транcдуктивную постановку.
11. Под шумом сеть без физического остатка оставила в окнах покоя меньшие флуктуации, чем PINN, и сохранила направление скачка WPE/SpEn; преимущество физического остатка под шумом в этом бенчмарке не показано (оно есть без шума: точность V и оценка w).
